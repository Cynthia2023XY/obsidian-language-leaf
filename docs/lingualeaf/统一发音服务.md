# 统一发音服务

2026-10-27。查词面板、词典音标、划词自动发音、内置复习及 SR 标题发音统一经过 `utils/helpers.ts`。

## 路由与错误处理

单词优先使用本次会话中词典返回的录音地址；没有录音时构造有道单词发音请求（英音 type=1、美音 type=2）。已有设置中的 0 仍表示美音，设置文件不迁移。短语和句子直接系统朗读，不再反复请求可能 HTTP 500 的 dictvoice 短语地址。指定音标录音按钮先尝试该录音，失败后使用系统朗读。

下载使用 Obsidian requestUrl 避免渲染器跨域限制。底层传输不能真正取消，服务会取消等待并丢弃迟到结果；不会将旧请求播放出来。生成有 6 秒上限，在线临时故障最多重试一次。状态码、Content-Type、大小与基本 MP3/WAV/Ogg 特征均校验，最终还需实际播放器能解码、产生 playing/start 事件。播放启动超时 6 秒，总时长上限 120 秒。

系统语音按卡片语言与口音选择，等待 voiceschanged；缺少指定口音时允许同语言降级并显示提示，没有该语言声音时明确失败。系统朗读成功开始前不显示成功。系统声音可能由操作系统联网提供，首版不保证离线或自动下载语音。

成功开始播放的音频采用内存 LRU，最多 32 项／8 MiB。缓存键包含提供方、文本、语言、口音和具体录音地址；失败音频立即剔除。系统朗读不缓存伪造音频文件。禁用插件清空缓存；缓存不写进 Vault。

新播放请求替换旧请求；查询变化、切卡、编辑／关闭复习窗口、关闭查词面板或禁用插件停止本服务播放。取消系统朗读调用浏览器 speechSynthesis.cancel，可能同时取消同一渲染器中其他来源的系统朗读，这是 Web Speech API 的限制。

查词面板及内置复习发音按钮附近显示加载、播放、系统备用／口音降级与失败信息，失败可重试。手动发音全部失败时另有带重试按钮的通知；自动发音不反复弹通知。诊断仅记录提供方、错误代码和耗时，不输出原文和 URL。

## 本地 TTS 扩展

`pronunciation/service.ts` 定义 `PronunciationProvider`、`PronunciationRequest`、`PronunciationOutput`，构造服务时注入有序提供方列表。本地 HTTP TTS 实现 supports/generate，可返回音频字节（统一播放）或独立适配系统任务。其 AbortSignal 必须传入支持取消的 HTTP transport；不支持服务端取消时也须丢弃迟到响应。

未来新增配置：地址、协议／路径、模型、声音、语速、可选鉴权、连接测试和备用策略。适配器的 cacheKey 必须包含服务身份、模型、声音、语言、文本、语速及其他影响音频的生成参数；不得包含明文令牌。地址、鉴权、请求格式因具体服务而异，本次不添加不可用设置项，不预设用户服务协议。可在系统提供方前插入本地适配器，并单独提供连接和短句实播测试。

## 验证范围

自动测试覆盖响应校验、录音优先、口音映射、有限重试、缓存隔离、失败不缓存、取消与迟到响应、去重、备用路由、系统声音选择及实际播放器事件清理。Mac Obsidian 内的系统语音真实出声仍需人工试听，自动测试不代表已确认设备具有可用系统声音。

## 声音选择与试听

设置中提供“启用系统朗读”和“系统朗读声音”（刷新列表、试听）。保存语音 voiceURI，兼容旧名称；声音选择对所有播放入口生效。关闭系统朗读后不进行系统备用，短语和句子没有其他来源时明确提示；设置中的试听仍可主动使用系统语音。

自动选择在同语言中排除已知特殊效果声音，优先所选英美口音，再按增强／高品质命名、常用普通声音及系统默认排序；这是启发式规则，并非 Web Speech 提供的音质检测。用户显式选择优先；选中的声音缺失或语言不匹配时不悄悄替换。声音显示名称与语言，播放状态也显示实际声音名称。切换声音或开关会停止当前播放；关闭设置页停止试听并移除声音列表监听。
