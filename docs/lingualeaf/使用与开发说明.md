# Language Leaf · 语叶

当前流程：普通文章 → 查词与收录 → 同篇 SR 闪卡 → Spaced Repetition 复习。

## 四条命令

| 命令 | 行为 |
| --- | --- |
| 切换当前文档为学习模式 | 切到原生阅读并启用划词；再次执行退出。关闭或在同一标签切换文件也会退出 |
| 打开单词列表 | 原表格独立标签页，保留搜索、标签 AND/OR、状态筛选、排序、分页和展开区 |
| 打开查词面板 | 左侧词典，可直接输入词句查询 |
| 打开新词面板 | 右侧表单，固定当前或最近活动的 Markdown 文章，手工录入后保存为本文闪卡 |

Obsidian 自动添加一次 `Language Leaf:` 前缀。标题栏和工具栏提供同一套学习入口，没有旧阅读命令。

## 日常学习

1. 打开普通 Markdown，执行“切换当前文档为学习模式”，无需 frontmatter 或包绕标记。
2. 按住设置的修饰键，在同一普通正文段落内划选单词或短语。
3. 左侧显示词典，右侧填入词句、原段落、已有译文和文章大纲。填写语境释义，可设置五档状态、标签、多条笔记和多条例句。
4. 检查表单底部的保存文章，点击“提交”。内容只增改这张闪卡，保留 SR 最新调度注释。
5. 在 Spaced Repetition 中复习。

手工新词也需要来源文章。没有可用 Markdown 时，面板显示提示并禁用提交，不写入隐含数据库或其他文件。学习会话按视图隔离，关闭后不自动恢复。

Shift 自带扩选旧锚点的行为，插件固定本次按下的位置并使用原生 Selection 更新高亮；也可选择 Alt / Option。首版支持原生阅读视图的普通正文段落，代码、嵌入、复杂表格及跨段选择不作为收录入口。

## 简化设置

保留学习语言、划词修饰键、查词自动发音、SR 卡片自动发音、美式/英式口音、补充段落翻译、五个原有词典的启用开关，以及 SR 卡组标签和多行问答分隔符。点击“保存设置”后生效。

默认卡组 `#flashcards`，分隔符 `?`，需与 SR 一致。已有卡片时不能直接改变分隔符。语言默认英语，也可使用法语或文章的 `ll-language`。法语当前支持独立身份、手工收录和 SR 复习，自动划词暂不接入法语在线词典。

没有服务器、数据库、自动导出、旧阅读器排版、迁移、每日复习限额或引擎选择配置。插件不启动旧数据库或服务端，不迁移旧数据。

## 双语和大纲

英文段落后紧跟折叠译文即可关联：

```markdown
The old bookmark was gone.

> [!translation]-
> 旧书签不见了。
```

已有译文优先；缺省且允许补充翻译时，发送原段落到有道。译文按段落处理，不伪造成精确句译。插件内置双语样式，隐藏背景、图标和标题文字，保留折叠箭头和点击区域；展开译文使用淡色文字及左侧竖线，无需额外 CSS snippet。

文章可添加唯一的 `ll-outline` YAML 代码块：`schema: 1`，`items` 数组中每项包含 `text`。收录时保存大纲快照。后续修改大纲不批量覆盖历史卡片，编辑单张卡片时可修改快照。

## SR 闪卡与持久化

随文闪卡使用 `#word`、H4 词句标题、多行问答分隔符和连续答案字段，包含原句、译文、笔记、例句及大纲。管理注释 `ll-card`、`ll-meta`、`ll-end` 记录稳定身份和表单结构。可直接手改可见内容，索引以可见字段为准。

SR 生成 `<!--SR:...-->`，插件不自行调度或伪造评分。保存通过 `Vault.process` 增量更新，并从最新原文保留 SR 注释。同文同词合并，不同文章可有各自语境卡。

`LinguaLeafData/` 只保存收词操作日志、全局词条快照、删除意图和必要的操作备份。启动时自动重试中断写回。没有内置评分事件、算法、暂停排程、迁移、引擎转换或完整备份导入导出。文章和数据目录可纳入用户自己的 Vault 备份。

删除卡片前备份原文。文章在插件外删除后仍可显示已确认的全局词条快照，但物理 SR 卡片及其调度会随文章消失。已有旧数据保持原状，不自动迁移或删除。

## 开发验证

运行 `npm ci`、`npm run test:run -- --pool=forks --poolOptions.forks.singleFork`、`npm run build`。`node scripts/lingualeaf-smoke.mjs` 验证四条命令、精简配置、真实表单和 SR 评分；`node scripts/lingualeaf-selection-smoke.mjs` 验证划词。

脚本限定在“新功能测试仓库”；界面验收时该窗口需处于可见状态，Obsidian 后台窗口会暂停原生阅读渲染。每轮新建独立测试文章。DOM PointerEvent 验证不等于真实硬件鼠标或触屏验收。

模型、Markdown 格式和文件端口继续与宿主分离，便于未来独立载体复用；独立产品的复习调度及联网同步另行设计，本版不携带未启用的内置复习实现。
