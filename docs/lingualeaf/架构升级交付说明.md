# Language Leaf 架构升级交付说明

交付日期：2026-11-13。插件版本保持 0.5.0，本次为本地迭代，代码按本次升级范围提交，没有创建 Release。

## 已交付

| 范围 | 实现与行为 |
| --- | --- |
| 学习实体 | `learning-core.ts`、`library-schema.ts` 分离词条、学习资料、复习卡片；磁盘 schema 3，界面通过兼容投影继续使用现有表单。卡片 ID 和 FSRS 归属保持稳定。资料按自身 ID 定位，不再由文章路径决定其身份。 |
| 词条身份 | 改词时重绑词条，保留此卡已有复习进度；改成已存在的表达时复用其词条身份，各语境卡片不合并评分链。旧数据中的词条身份碰撞在格式升级时隔离。 |
| 幂等保存 | 收录请求保留原始确认结果；请求已提交而确认丢失后，重试先确认请求身份，再判断编辑版本，后续人工编辑不被旧请求覆盖。 |
| 共享配置 | 每日新卡额度和保持率按字段提交、按字段基线检测冲突；学习日时区及切换小时单独保存，配置有独立版本。 |
| 业务核心 | `LearningRepository`、`ReviewRepository` 是业务级接口；`LearningCore` 可通过浏览器构建，不依赖 Obsidian、Node 文件 API。桌面本地装配由 `LearningLibrary` 提供。 |
| 复习服务 | `review/service.ts` 负责队列、四档预览、评分、撤销、暂停、会话恢复和冲突；弹窗负责展示和交互。评分提交在同一跨实例锁内重查资料、设置和每日额度。 |
| 可重建索引 | `review/repository.ts` 维护当前状态、到期索引、学习日统计和会话统计；派生快照可删除或损坏后重建，权威来源仍是追加式评分历史。事件前缀复用已验证缓存。 |
| 刷新方式 | 目录按文件版本缓存，词库列表订阅文件变更，合并刷新，移除原先三秒一次的全目录轮询。 |
| 数据源管理 | 设置中提供创建、连接、追加导入三个入口；连接同时固定学习库 ID。待重载连接不会被普通设置保存覆盖。 |
| 第二库追加 | 对导入库和事件使用稳定命名空间，保留同名表达的不同语境和全部调度历史；先发布不可变事件，最后原子提交目录与导入账本，未完成导入的事件不可见，重试不会重复追加。 |
| 通用来源 | 支持 Obsidian、网页、电子书、手工来源；来源是可选引用，打开失败不影响学习资料使用。 |
| 旧模式隔离 | `legacy-adapter.ts` 独立承载原 Markdown 索引、操作恢复、删除备份和旧版写回。选择独立学习库后不运行旧写回路径。 |
| 阅读选区 | `reading-block.ts` 统一段落、标题、紧凑/宽松列表、嵌套列表和任务列表。实际文字交集决定块归属，跨块、代码、翻译区域和嵌入内容继续排除。记录块内偏移，重复单词不会用第一次出现的位置替代。 |
| 来源定位 | `source-locator.ts` 结合后处理器章节范围、结构和全文本校验，识别行内强调、链接、实体和转义。列表取当前层级文本块，标题只取标题，普通段落沿用短句扩展规则。 |
| 查询解耦 | 合法选区先打开词典查询，再尝试来源定位。定位失败时保留可见语境，并在表单标注“来源位置未确认”。查询序号、文档会话及渲染快照共同拦截旧结果。 |
| 译文配对 | 空行不打断邻接；段落/标题后 translation callout 与前块配对；列表项内缩进译文只属于该项，多个中文段落完整保留。整份列表后的译文不会被猜配给最后一项。 |
| 词典异步 | 所有词典在提交结果前检查当前请求权限，换词或卸载后旧请求不得覆盖新结果及加载状态。 |
| 同步边界 | `sync-contract.ts` 定义库身份、操作 ID、客户端身份、基线修订、删除/恢复、增量游标及冲突结果；同卡离线评分必须选择分支，不能按时间直接拼接。 |

## 保留的后续边界

独立客户端和实际跨设备同步没有实现，符合原方案先定义同步契约的范围。本次没有新增题型编辑界面，也没有提供“将两张卡的 FSRS 进度合成一张”的操作。

本地 catalog 仍采用单份原子元数据提交，单条资料修改仍会重写 catalog；索引更新时仍需枚举已发布事件路径。读取缓存、可重建快照和变更订阅已减少反复读取/重放历史，但这不是逐资料数据库或远程增量同步的实现。当前 Markdown 定位保留块范围与可见文本偏移，不提供完整的 Markdown 字符双向映射；无法证明精确位置时明确使用快照。

旧客户端不能读取 schema 3，升级后应让两个窗口都使用本次产物。需要回退时，先关闭两个库中的插件，再使用完整备份另建恢复库并恢复对应插件设置，避免旧代码覆盖当前学习库。
