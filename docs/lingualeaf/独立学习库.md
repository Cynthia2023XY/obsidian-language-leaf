# 独立学习库

Language Leaf 可以连接笔记库之外的本地学习数据源。收录时复制词句、语境释义、例句、译文和笔记；此后原文章只提供出处，学习库的编辑、删除和评分均不回写原笔记。原文章修改、移动或删除也不会改变已收录资料。

## 数据结构

- `catalog.json`：格式版本 2，包含学习库 ID、统一复习规则和完整语境卡片。每张卡片保留稳定 ID、词条 ID、可选来源、收录次数基数、幂等请求身份、内容版本和更新时间。
- `LinguaLeafData/review/events/`：原格式的追加式 FSRS 事件，保留到期时间、撤销、暂停和历史字段。
- `LinguaLeafData/review/sessions/`：按接入库区分复习会话。
- `migration-report.json`：迁移统计、来源库身份与备份位置。

同语言同表达共享词条身份和累计收录次数，不自动合并不同语境卡片及其评分历史。无来源的资料也支持收录、编辑、删除和复习。删除使用软删除，保留评分历史；旧文章不会被重新扫描并复活卡片。

## 迁移

在仓库根目录执行，默认只预览：

```sh
node scripts/migrate-independent-library.mjs \
  --vault '/绝对路径/原笔记库' \
  --destination '/绝对路径/独立学习库'
```

关闭原库的收录及复习，并停用旧插件，再追加 `--apply` 执行。工具读取当前文章、孤立词条快照、收录意图、删除记录及完整评分事件。先在外部备份全部 Markdown、旧学习数据和原插件设置，再将新数据源写入同级临时目录，校验旧评分状态和原文件 SHA-256 后发布。未知调度或历史缺失会停止迁移，不自动重置进度。

同一个原库向已迁移目标重跑时只返回统计，不重新导入文章或覆盖新版编辑。目标属于另一学习库时拒绝覆盖；本工具暂不提供第二个库的追加迁移。

迁移完成后，保留插件设置中的其他字段，设置：

```json
{
  "learning": {
    "libraryPath": "/绝对路径/独立学习库",
    "vaultId": "迁移报告中的 vaultId"
  }
}
```

重新加载插件。尚未迁移的其他库保持原有随文模式。新的接入库应使用自己的稳定 `vaultId`，不能复制来源库身份。接入已存在的共享数据源不等于导入该库的旧资料。

## 写入与故障边界

词库通过跨进程锁与原子文件替换保存，旧版本编辑会报冲突。评分事件采用写入临时文件后独占发布，两个窗口竞争同一版本时只允许一条成功。数据源缺失、损坏或无法访问时明确失败，不自动创建另一份空库。

普通写入锁记录进程身份，可回收已退出进程的锁。若在锁回收本身中断，可能遗留 `.catalog.lock.reaper`；确认没有进程操作该库后再处理，不能强行抢占活跃写入。

这是桌面端、同一台机器的共享目录。该外部目录不在原笔记库的同步范围内，需要单独备份；直接通过网盘同步多个离线写者不属于本版支持范围。来源路径是收录时记录的引用，文章改名后可能无法跳转，但资料和进度始终保留。

旧卡片和旧数据仍原样留在原库作为恢复依据。切换回旧数据源不会包含迁移后新产生的学习数据，恢复前需核对差异。
