# 内置复习实施与验收

2026-10-26。编码前基线提交：`0d42b74`。未发布新版本，未自动迁移任何实际卡片。

## 已接入

`review/engine.ts` 封装锁版 ts-fsrs 5.4.1（FSRS-6）、日期转换、方向键、四档候选与只创建的版本事件存储。每次评分携带计算时间、操作时间、保持率与参数版本；候选超过一分钟时更新并要求重新选档。采用默认模型参数，关闭随机模糊，预览与提交保持一致。

`review/modal.ts` 提供专注回忆界面：单一原生关闭按钮，答案揭晓后显示原句，译文、笔记及概览可展开。按钮文案为不记得／不确定／记得／简单，对应左／下／上／右。输入框、长按和组合输入不评分。未到期的学习卡等待到期，评分写入成功后才推进队列；保存失败锁住本卡并保留同一操作重试。

内容仍以 Markdown 为权威，内置格式使用 schema 2 与 `ll-answer` 标记，不包含 SR 问答分隔符或调度。实际 SR 1.15.4 解析器验证内置卡片不会被收录，两种卡片可以混排。修改内容保留卡片 ID；独立进度不会重置。无有效来源的快照不入队。

`review/migration.ts` 与 `import-schedule.ts` 提供只读预览、逐卡选择、完整文件备份及局部卡片替换、完整 FSRS 状态导入、旧 SM-2 近似转换、主动重置、中断恢复、复习前回退。卡片修改冲突时停止；回退不覆盖其他正文。开始内置复习后禁止恢复旧 SR 进度。自定义旧参数和复习日志不导入。

## 当前边界

- 当日额度按本机时区凌晨 4 点计算，跨时区后跟随本机；首版未提供固定时区配置。
- 支持全库和当前文章范围；首版未提供按标签筛选复习队列或跨文章合并调度。
- 只维护一个复习窗口。版本日志对并发写入和同步冲突采取拒绝覆盖策略，不提供跨设备实时协同。
- 回退保留所有备份与导入日志；首版不支持同一卡片反复迁移，也不提供已评分卡片的双向算法切换。
- 译文、笔记等作为纯文本渲染；任意 Markdown 多媒体与复杂卡型不在首版范围内。
