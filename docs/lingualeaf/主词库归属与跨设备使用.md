## 同步与本机文件

随 Cynthia Note 同步：

- `catalog.json`：词条、学习资料、卡片、收录确认、共享复习配置。
- `LinguaLeafData/review/events/`：完整追加式评分、撤销、暂停和导入事件。
- `relocation-report.json`：本次迁移校验记录，不包含词句内容。

本机运行文件位于所属笔记库之外的同级 `.language-leaf-local/<目录摘要>/`，包含写入锁、原子发布临时文件、可重建状态索引和会话断点。无论同步工具是否排除隐藏文件，它们都不位于本次笔记库的同步范围内。不同设备独立维护本机运行区。

## 使用边界

切换设备之前先完成当前设备上传，在目标设备下载完成后再学习、复习。当前文件同步不支持两个设备离线同时修改同一词库后的自动业务合并，遇到同步冲突需先处理冲突。移动端存储适配尚未实现，插件仍仅支持桌面。

原库外地址已经退役；不要把原目录或完整备份重新连为活动词库。需要恢复时先停止两个入口，再从备份单独恢复并重新绑定，避免出现两个活动来源。

## 可复用迁移命令

先不带 `--apply` 预览，再显式执行；脚本使用正式迁移服务，重跑不会再次追加卡片。

```bash
node scripts/relocate-library-into-vault.mjs \
  --source '/Users/dingxinyi.2/Documents/Obsidian Notes/Language Leaf Library' \
  --vault '/Users/dingxinyi.2/Documents/Obsidian Notes/Cynthia Note' \
  --secondary-vault '/Users/dingxinyi.2/Documents/Obsidian Notes/雅思' \
  --apply
```
