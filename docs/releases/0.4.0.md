# Language Leaf 0.4.0

- 新增短句上下文扩展：默认在目标句少于 15 个单词时，纳入前后各一句；可在设置中调整阈值和句数，任一项设为 0 即关闭扩展。
- 扩展时保留原有自然段和换行，同段已有句子计入扩展范围，不跨标题、代码块或普通引用。
- 扩展边界落在对话引号内部时，补齐完整对话，避免截断或留下孤立引号；实际纳入句数可能超过配置值。
- 完整段落均有对应译文时，优先按原顺序保留文章已有译文；其他情况沿用可选的自动翻译，并保留分段。
- 修复例句和译文在保存、重新编辑及复习时丢失换行的问题，并补充处理第三方译文中的异常实体字符。

设置仅影响之后收录的例句，不自动修改已有卡片。
