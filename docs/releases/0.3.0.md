# Language Leaf 0.3.0

## 修复

- 修复 Obsidian 新版设置页将所有配置挤在一行、中文逐字换行的问题。
- 恢复三指划选查词：支持松开修饰键查询，并提供可选的划选后自动查词和选区查询按钮。
- 修复 macOS 闪卡保存快捷键：在新词面板优先处理 Command+Enter，阻止 Control+Enter 意外提交；Windows/Linux 使用 Ctrl+Enter。
- 切换到编辑视图时退出学习模式，查询命令可恢复命令面板打开前的有效选区。

## 功能

- 发布内置 FSRS-6 词句复习，支持专注回忆与语境对照布局、每日新卡片上限、目标保持率、撤销及暂停恢复。
- 提供 SR 卡片迁移预览、备份与评分前回退；已有卡片不会自动转换。
- 统一发音服务，增加系统英语声音选择、试听与播放状态。
- 完善闪卡字段、段间留白及旧卡片/SR 进度兼容。

## 兼容与验证

- 适用于桌面 Obsidian 1.14.4 及以上。
- 更新保留 data.json、Markdown 笔记及 LinguaLeafData 学习数据。
- 142 项自动化测试通过，类型检查和生产构建通过；交互修复经用户确认。
- 保留 0.2.11 的审核兼容、安全依赖与样式修复，标准附件通过 GitHub Actions 构建并生成来源证明。
