# Language Leaf 0.5.0

统一内置复习，并改进复习状态和学习笔记展示。

- 新卡片统一使用语叶内置 FSRS，移除 SR 引擎、卡组标签和问答分隔符设置。旧 SR 设置会归一为内置复习；已有 SR 卡片需通过“迁移 SR 卡片到内置复习（预览）”导入，不会因升级自动改写笔记或迁移进度。
- 单词列表新增“下次复习时间”，区分待首次学习、已到期、已暂停及迁移未完成等状态；评分、撤销和暂停后自动刷新。
- 复习弹窗加载、休息和完成状态预留正文空间，减少弹窗高度跳变。
- 学习笔记保留换行和空行；旧卡片正文与快照一致时恢复原始换行，手工修改的正文优先。
- 复习弹窗和单词列表展开区支持笔记 Markdown 渲染，包括加粗、行内代码、代码块和列表。
- 修复 Markdown 普通换行被重复计行的问题，统一段落间距，保留代码块内部空白。

最低支持 Obsidian 1.14.4。学习数据与复习进度保留在当前笔记库。
