# Language Leaf 0.6.0

新增独立学习库，支持库内主词库与本机其他笔记库连接，并改进原生 Markdown 阅读选词。

- 学习资料、词条与复习卡片独立保存，保留卡片身份及 FSRS 进度；已迁移的学习库不再回写来源文章。
- 设置提供创建、连接和追加导入学习库入口，支持校验学习库身份、保留调度历史及中断重试。
- 主词库可使用笔记库内相对路径随笔记同步；其他笔记库的外部连接按设备保存，新设备需要重新绑定。
- 复习服务支持共享配置冲突检测、额度竞争保护和可重建索引；锁、临时文件和会话等运行文件保留在同步目录之外。
- 改进标题、列表、嵌套列表和任务列表选词，保留重复词的选区偏移与邻接译文；旧词典请求不会覆盖新查询。

最低支持桌面 Obsidian 1.14.4。未迁移的安装保留随文卡片模式，不自动搬迁已有笔记。升级前请备份学习数据；旧版本不能读取 schema 3 学习库，访问同一词库的窗口应一起升级。跨设备使用需先上传、再下载完成后学习，不支持多设备离线同时修改后的自动合并。本次不提供独立同步服务或移动端适配。
