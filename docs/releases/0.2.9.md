# Language Leaf 0.2.9

First release from the independent Language Leaf repository.

- Read native Markdown, look up words and sentences, and save Spaced Repetition flashcards in the same note.
- Update affected dependencies and align the Node, TypeScript, test, and build toolchain.
- Add English installation, usage, privacy, and attribution documentation.
- Build and attest the standard plugin assets using GitHub Actions.

Install main.js, manifest.json, and styles.css into your vault configuration folder under plugins/language-leaf/. Keep any existing data.json. Requires desktop Obsidian 1.14.4 or later.

Community Directory approval and actual Obsidian runtime verification are separate from this GitHub release. The original Language Learner MIT attribution remains in the repository.
